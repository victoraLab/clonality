Clonality Sharing Circos Viewer

Paste either a square sharing matrix or the original clonotype table and render a browser-based Circos-style plot for BCR/TCR sharing.

Paste `id,size,group` style data. The plot will sort clonotypes from larger to smaller within each group and leave unique clonotypes visible with no ribbons.

Ready. Paste data and click Render Plot.
  • `Clonotype table` mode imitates the old Circos idea: ideogram-like clone bands plus ribbons only for shared clonotypes.
  • `Sharing matrix` mode keeps the faster D3 chord view for already summarized data.
  • Accepted separators: comma, tab, semicolon, or multiple spaces.

Interactive Plot

Hover groups, clonotype bands, or ribbons to inspect sharing and unique regions.
